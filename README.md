First real hobby project of mine. At its current stage it is functional but still a buggy mess.
It should work on all different variations of canvas URL's, but if not its probably because it doesn't follow the 
[your institution's name].instructure.com or canvas.[your institution's name].edu format.

It is not published on the chrome web store at the moment. 
Meaning after you copy the repository you will need to type "chrome://extensions/" into the chrome browser
then make sure developer mode in the top right corner is on, 
then click "load unpacked" in the top left corner and navigate to the file named "Canvas Assignment Manager" or whatever you named the repo
finally make sure the extension is on, navigate to canvas, make sure canvas is in card view, 
and hopefully the right side of the screen will give helpful information.
